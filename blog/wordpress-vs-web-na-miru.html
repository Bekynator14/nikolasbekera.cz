WordPress vs. web na míru — co je lepší pro malou firmu?

WordPress používá 40 % internetu. Ale neznamená to, že je správnou volbou pro každého. Kdy dává smysl WordPress a kdy je lepší web napsaný od základu?

Nikolas Bekera·Květen 2026·5 min čtení

Jednou z nejčastějších otázek, které dostávám, je: "Nemůžu si to udělat sám na WordPressu?" Nebo: "Proč bych platil za web na míru, když WordPress je zadarmo?"

Odpověď není jednoduchá — záleží na tom, co od webu očekáváte a jak ho budete používat.

Hlavní nevýhody WordPressu

WordPress je výkonný nástroj, ale nese s sebou náklady, o kterých se nemluví tolik jako o té "bezplatné" vstupní ceně:

  • Rychlost: průměrný WordPress web se načítá 3–6 sekund. Web napsaný od nuly zvládne pod 1 sekundu. Google rychlost hodnotí jako SEO faktor.
  • Bezpečnost: WordPress je nejčastěji napadaný CMS na světě. Bez pravidelných aktualizací jádra, šablon a pluginů riskujete kompromitaci webu.
  • Pluginy: každý plugin přidává závislost. Pluginy se přestanou vyvíjet, dostávají bezpečnostní chyby, nebo se vzájemně rozbijí po aktualizaci.
  • Skutečné náklady: prémiová šablona + prémiové pluginy + hosting pro PHP/MySQL + správce webu = každý měsíc platíte víc, než čekáte.

Kdy WordPress dává smysl

Přesto existují případy, kdy WordPress je správná volba:

  • Potřebujete pravidelně psát a publikovat obsah sami (blog, novinky, produkty)
  • Váš e-shop má stovky produktů (WooCommerce)
  • Máte interního správce, který bude web udržovat
  • Potřebujete pokročilé funkce jako rezervační systém, členskou sekci nebo vícejazičnost

Kdy je lepší web na míru

Pro většinu živnostníků, řemeslníků a malých firem platí, že web na míru je lepší volba:

  • Web nepotřebujete každý týden aktualizovat — stačí kontakt, služby, reference
  • Chcete maximální rychlost a čisté SEO bez zbytečného kódu
  • Nechcete se starat o aktualizace, zálohy a bezpečnostní chyby
  • Preferujete jednorázovou platbu bez měsíčních poplatků za pluginy
Konkrétní příklad Instalatér s jednostránkovým webem na míru: načítání 0,8 sekundy, skóre PageSpeed 98/100, žádné pluginy, žádné aktualizace. WordPress web podobného rozsahu typicky dosahuje skóre 55–70 a načítá se 3–5 sekund. Google to vidí.

Jak se rozhodnout?

Zeptejte se sami sebe: budete web sami pravidelně editovat? Pokud ano — WordPress nebo jiný CMS dává smysl. Pokud ne a web hlavně potřebujete proto, aby vás zákazníci našli a zavolali — web na míru vám ušetří peníze, starosti a bude fungovat lépe.

Jednostránkový web na míru se mi vrátí za 3–5 let platby za hostingový balíček s WordPressem. A za tu dobu jsem nemusel nic aktualizovat.
